# Activity-Booking-App

A simple RESTful API built with **Node.js**, **Express**, and **MongoDB** that allows users to register, log in, view public activities, book activities, and view their bookings.

## Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
- **Validation**: Joi
- **Password Hashing**: bcrypt

## Setup Instructions

npm install
Environment Configuration .env file
Run the Server
